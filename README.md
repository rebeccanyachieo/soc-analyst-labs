# SOC Analyst Labs

Hands-on cybersecurity portfolio focused on developing practical SOC skills through log analysis, system investigation, and security labs.

## Approach

This repository focuses on understanding how systems behave under normal conditions and identifying deviations that may indicate suspicious activity.

Each lab emphasizes:
- Observing system behavior  
- Applying structured analysis  
- Documenting findings clearly  

## Platforms

- Self-Created Labs

- Security data analysis and visualization

## Projects

### Shodan Port 104 Analysis
Analyzed Shodan data for internet-exposed port 104 hosts using Python, pandas, Jupyter, and matplotlib. 
Explored geographic and organizational patterns while separating internet exposure from evidence of vulnerability.

### Windows Security Monitoring Lab

Generated and investigated Windows security events using Sysmon and Splunk, including failed logons and account activity.
